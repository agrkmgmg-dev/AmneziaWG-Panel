# AmneziaWG Panel

پنل مدیریت سرویس‌های VPN برای ساخت و مدیریت کلاینت‌های AmneziaWG و WireGuard.

امکانات اصلی:

- ساخت خودکار Peer و تولید فایل Config و QR
- تعیین تاریخ انقضا، سقف حجم و محدودیت سرعت هر کلاینت
- مدیریت وضعیت، ترافیک و تمدید سرویس
- رابط مدیریتی سازگار با موبایل
- پشتیبانی از helperهای امن Docker و WireGuard روی سرور
